# BernieChiu557.github.io

Personal website of Yi-Hung Chiu, published at https://berniechiu557.github.io

Plain HTML and CSS, no build step. Edit the `.html` files directly:

- `index.html` — home
- `work.html` — resume, experience, projects
- `writing.html` — blog posts and photos
- `style.css` — the one stylesheet for all pages

Pushing to `main` republishes the site.
